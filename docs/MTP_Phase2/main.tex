\begin{abstract}
This work presents a two-stage pipeline for generating physically plausible 3D human motion from casual video. In the first stage, \emph{ViMo-Flow}---a diffusion-based video-to-motion framework---synthesizes kinematic 3D motion sequences conditioned on 2D pose trajectories extracted from unconstrained footage, enhanced by Min-SNR loss weighting~\cite{minsnr2024} and probabilistic vectorized timestep sampling~\cite{ptss2024} for improved convergence and temporal coherence~\cite{vimo2024}.

The second stage, the focus of this report, addresses physics-based imitation learning. A reinforcement learning policy drives a simulated humanoid in MuJoCo~\cite{mujoco2012} to reproduce reference motions under rigid-body dynamics. An adversarial training scheme employs body-part-specific discriminators whose bounded scores replace manual reward engineering, enabling composite multi-objective motion learning through weighted reward aggregation~\cite{iccgan2021, composite2023}. Proximal Policy Optimization~\cite{ppo2017} trains the policy using these discriminator-derived rewards. A motion retargeting procedure converts SMPL skeletal data to the simulation character via coordinate system transforms, per-joint bind rotations, and height scaling. Case studies on bilateral symmetry regularisation~\cite{symlocom2018} and phase-conditioned observations demonstrate accelerated convergence on simple locomotion with trade-offs on complex, asymmetric motions.

A planned third stage of policy adaptation~\cite{adaptnet2023} will address robust deployment across varying simulation conditions.
\end{abstract}
