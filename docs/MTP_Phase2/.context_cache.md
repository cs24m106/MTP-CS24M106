# MTP Phase-2 Context Cache

## Pipeline Overview
- **Stage 1 (ViMo-Flow):** Diffusion-based video-to-motion. 2D poses → 3D kinematic motion via DDPM with Min-SNR + PTSS. Outputs SMPL format (24 joints, axis-angle, Y-up).
- **Stage 2 (Physics-Based Imitation):** Adversarial RL in MuJoCo. Discriminator-driven rewards + PPO train policy to reproduce reference motions under rigid-body simulation. Composite multi-discriminator for body-part-specific evaluation.
- **Stage 3 (Future):** AdaptNet policy adaptation for deployment robustness.

## Retargeting Pipeline (smpl_converter.py)
1. Coordinate transform: SMPL Y-up → MuJoCo Z-up via G = [[0,0,1],[1,0,0],[0,1,0]]
2. Height scaling: s = MuJoCo_leg_length / SMPL_leg_length (~0.9577)
3. Floor correction: min weighted avg of ankle+foot Y across frames
4. Bind rotations: per-body Rodrigues rotation aligning rest-pose bone dirs
5. Chain composition: multi-SMPL-joint → single MuJoCo body
6. Output: DeepMimic JSON (pelvis pos+quat, 14 body quats, 30 Hz)

## Case Studies
- **Bilateral Symmetry Loss:** _SYM_RIGHT/LEFT_IDX (11 pairs), _SYM_SIGNS for sagittal flips. L_sym = MSE between mirrored policy means. Helps simple gaits, hurts complex motions.
- **Phase-conditioned Obs:** sin(2πφ), cos(2πφ) appended to goal slice. φ = normalised cycle position. Helps looped motions, alters architecture.
